# Bug Log

Every test or pipeline failure found and fixed, one row per failure (Spec 000 RF-95). When the AI
sees a red test or pipeline run, it fixes the cause and adds or updates the row before finishing
the task (AGENTS.md, "When finishing any task").

Columns:
- **Date**: the day the failure was found (`YYYY-MM-DD`).
- **Bug / failure**: short name of what failed, with the test case or job when there is one.
- **Passed ✅**: only the mark ✅, once the failed tests passed again after the fix; empty while they have not.
- **Failed ❌**: only the mark ❌.
- **Cause**: why it failed and where (GitHub run, job, local command or test).
- **Solution**: the fix, or why no code was changed; the re-run that proved it; the files changed and the commit.
