# Bug Log

Every test or pipeline failure found and fixed, one row per failure (Spec 000 RF-95). When the AI
sees a red test or pipeline run, it fixes the cause and adds or updates the row before finishing
the task (AGENTS.md, "When finishing any task").

Columns:
- **Bug / failure**: short name of what failed, with the test case or job when there is one.
- **Passed ✅**: where it passed after the fix (run, command or commit); empty while it is not fixed.
- **Failed ❌**: where it failed (GitHub run, job, local command or test).
- **How it is fixed**: the cause and the approach.
- **Solution**: the change that fixed it (files and commit).
